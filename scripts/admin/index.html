図鑑の編集室

下書きと未承認候補は .editor/ に保存し、公開しません。「公開用データへ反映」はローカルファイルの更新です。確認・テスト後、GitHubのPRで承認してからデプロイしてください。公開サイトに管理APIはありません。

構造化データ（出典・分類・公開状態など）

石の固定IDとURLは変更できません。未確認情報を推測で埋めず、出典の確認日も記録してください。料金・診断ロジック・購入履歴はフェーズ2です。

210種類の写真を選ぶ

石を選ぶ → 写真と出典を入力 → プレビュー確認 → 採用 → 承認済みを一括反映。コード・JSONの編集は不要です。

1. Macから写真を選び、出典を登録

JPEG・PNG・WebPを選び、出典とライセンスを入力してください。Commons画像・自社撮影・個別許諾に対応します。

2. プレビューと利用条件を確認

採用後も図鑑にはまだ公開しません。下の一括反映ボタンで承認済みだけを反映します。

JPEG・PNG・WebP対応。HEICは端末でJPEGに変換してから選択してください。追加だけでは承認・公開しません。

3. 承認済み写真をまとめて図鑑へ反映

210種類の写真登録状況

収集する石を選ぶ（210種類の状態一覧）
自動検索・既存候補から選ぶ（必要なとき）

検索語は形状の証明ではありません。石種・実物写真・形状は候補ごとに確認してください。

寸法は検索元の原画像、アップロードは保存候補の画素数です。ピント・自然な色・艶・背景・被写体の大きさ・透かしの有無は目視で確認し、見た目より石種の正確性を優先してください。

候補の確認・編集

写真候補を選んでください。

詳細情報（通常は編集不要）

ライセンス不明・非商用・改変禁止は採用できません。採用後の画像は縮小・WebP変換し、撮影者とライセンスを公開します。元ファイルは自動削除しません。
