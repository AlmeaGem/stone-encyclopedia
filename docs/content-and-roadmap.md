# 210項目の移行と次の開発

## 移行したもの

ユーザーが以前添付した `stone_catalog.json` の石名・固定ID・別名・テーマ・取り扱いメモだけを、今回の公開図鑑へ再構成しました。**Managerのリポジトリ・DB・Storageを移行元にはしていません。** 原本JSON、書籍画像、組み合わせレシピの原文、在庫・原価・仕入先・写真・個人情報は新リポジトリへ含めていません。

- `s001`〜`s210`：210件を維持。
- 個別の英語URL：210件。ID・URLは管理画面から変更できない。
- 名称分類：鉱物・宝石名、変種・色名、流通名、岩石・天然ガラス、有機物、結晶形状。
- 英語の検索見出し、代表色の検索ラベルを編集部で追加。個体の同定・鑑別情報とは分けて表示。
- 公開用の短い紹介・品質・伝承・選び方・浄化／取り扱い・関連ページを作成。元の一言要約をそのまま転載しない。
- 読みもの6本を独立した編集記事として新規作成。

## 確認待ちを推測で埋めない

元資料には鉱物名、硬度、内包物の同定、実物ごとの処理の確認、公開して引用できる書名・版がありません。そのため初期210件の鉱物名・硬度などは**未確認**と表示します。専門家の鑑別情報や一次資料と照合した場合だけ、出典URL・確認日・注記を追記してください。

この初期版は、210件を閲覧できる動作するプレビューですが、210件の学術的な項目がすべて検証済みの完成図鑑ではありません。本番で検索流入を狙う前に、人気石から一次資料・独自写真・説明を整備します。類似の短い説明だけの状態を「SEO記事の完成」とは扱いません。

確認が特に必要な項目：流通名の鉱物同定、色・処理による呼び分け、親石から補助作成された6項目、結晶形状17項目の区別、元の別名に幅があるもの、書誌情報と権利。公開する全ページに確認状況とページ編集日を表示しています。編集日は資料検証日とは別です。

## 写真

初期採用は0枚。権利不明の写真で数を埋めません。写真なしでも図鑑は閲覧でき、抽象的な色イメージであることを表示します。候補収集・手動登録・採否・権利と一致の確認・最適化・クレジットは実装しています。環境からCommonsへ接続できない場合はエラーとし、公開情報を変更しません。

## フェーズ3・公開前の操作

1. 運営者名・連絡先・法定表示・規約・返金条件を所有者が確認。
2. 未確認の石データと原稿・ライセンスをレビュー。
3. 別の本番ホスティング・独自ドメインを所有者が設定。
4. 料金・条件に同意してから本番公開を決定。
5. Search Console・サイトマップ・計測の導入。

決済鍵・APIキーはチャットやコードに追加せず、将来の**新プロジェクト**の環境変数へ設定します。本番決済の開始前には実際のテスト購入と権限確認が必要です。
