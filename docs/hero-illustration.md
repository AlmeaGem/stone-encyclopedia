# トップの画像方針

丸玉の生成イラストは撤去しました。利用許諾と実物であることを確認済みの写真がないため、現在はタイポグラフィ中心で表示します。トップの文章とCTAは維持しています。

## ヒーロー見出しの装飾

見出し右側には `src/components/HeroGem.astro` の軽量なインラインSVGを配置しています。淡いピンクの透過面、シャンパンベージュの細いカット線、小さな光の点を組み合わせた抽象的な宝石です。実物写真の代替にはしていません。

画像ファイル・外部取得・JavaScript・アニメーションは追加せず、装飾はaria-hiddenとpointer-events:noneで読み上げや操作の邪魔をしません。見出しの行幅を変えず、文字を上のレイヤーに配置します。375／390／430／768／1440pxで確認し、画面画像は `docs/screenshots/hero-accent/` に保存しました。
