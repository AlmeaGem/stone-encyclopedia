# 願望検索・公開文章・カテゴリー番号の改善

## 変更内容

- 番号1〜12に2桁分の非縮小幅・横書き・改行禁止を指定。名前・説明・矢印の位置を統一。
- 願望カテゴリー上部の大きな免責ボックスと掲載ID順の説明を撤去。必要な説明は共通フッター・利用規約・購入前案内に集約。健康カテゴリーの注意は維持。
- 登録済み伝承タグを、選択状態とチェックが分かるピル型ボタンとして実装。ブラウンの文字、淡いピンク、控えめな立体感、44px以上のタップ領域、focus・hover・押下状態に対応。
- 記事・案内ページ・共通帯などの制作側の文章を読者向けに整理。石・記事・カテゴリーの元JSONは変更せず、公開時の文章を別の表示層で扱います。
- 正式な参考文献と画像ライセンス表示、未確認の鉱物情報を未確認と示すこと、有料診断の販売準備中表示は維持。

## 絞り込みの仕様

1. カテゴリーに既に関連付いている石を対象に、その石の登録済み`themes`だけをボタン化します。
2. 複数選択はANDです。選んだタグを**すべて持つ石**を、元の掲載順のまま表示します。評価・順位付け・スコア計算はしません。
3. 同じボタンで解除、「すべて表示」で全解除。件数は表示中の石の実数で「○種類の天然石」と更新します。該当なしはテーマを減らす案内を表示します。
4. 選択はURLの`theme`パラメーターに反映。再読み込みで復元し、不明なタグは無視します。canonicalは元のカテゴリーURLを維持します。
5. JavaScriptを無効にした場合はボタンを表示せず、カテゴリーの全件一覧を閲覧できます。API・AI・個人情報の送信や保存は追加していません。

## 関連付けが未設定の細かな願望

元の「新しい出会い」「理想の関係を見つめる」等の小分類には、石IDや伝承タグとの明示的な関連がありません。**根拠のない対応付けはしていません。**これらの細目名を使った絞り込みには、運営者による関連付けの確認が必要です。

元の小分類データは保持し、[確認用一覧](internal/wish-link-review.json)にカテゴリーごとの未設定細目と利用可能な登録済みタグを整理しました。このファイルは公開ビルドには含めません。現在の無料ボタンは確実な既存の伝承タグで操作できます。

個別ランキング・おすすめ7選・オーダーメイド組み合わせ・個人向けレポートは無料機能に追加していません。790円のレポートは販売準備中で、決済は無効のままです。
