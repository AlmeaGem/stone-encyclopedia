# カードの操作位置・記事詳細の改行

石カードのリンクと本文を縦方向のFlexboxにし、本文の長さにかかわらず「詳細を見る」をカード下端にそろえました。画面に追従する固定ボタンではなく、各カード内で位置がそろいます。本文と重ならない余白を確保し、トップ・図鑑検索・願い別・関連記事の共通カードへ適用します。

記事一覧だけでなく詳細のh1・h2にも共通タイトル処理を適用しました。句読点や「ものではありません」などのまとまりを保ち、長い見出しの末尾一文字だけが残る折り返しを抑えます。タイトル・記事本文・210項目のJSONは変更していません。

375／390／430pxとPC 1440pxで確認。文字数の異なるカードの下端からボタンまでの余白が一定であること、本文と重ならないこと、記事詳細の句が分割されないことを画面テストに追加しました。
