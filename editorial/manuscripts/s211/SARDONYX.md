古くからサードオニキスは、魔除けや守護のお守りとして親しまれ、家庭の平和や大切な人との絆を願う石として大切にされてきました。

スピリチュアルな世界では、サードオニキスは家族を災いから守り、温かな愛情と幸せな暮らしを育む石といわれています。

家族の健康や幸せを願うとき、パートナーとの絆を深めたいとき。

サードオニキスは、そんなときに相手への思いやりを思い出し、温かな関係を育むためのお守りとして親しまれています。

## サードオニキスの鉱物としての特徴

| 項目 | 内容 |
| --- | --- |
| 和名 | 赤縞瑪瑙（あかしまめのう） |
| 鉱物グループ | カルセドニー（玉髄）・石英グループ |
| 化学組成 | SiO₂ |
| 主な色 | 赤褐色・橙赤色・白色など |
| モース硬度 | 約6.5〜7 |
| 結晶構造 | 微細な石英結晶の集合体 |
| 主な産地 | ブラジル、インド、ウルグアイなど |
| 特徴 | 赤褐色と白色などが重なる縞模様 |

サードオニキスは、カルセドニー（玉髄）の一種で、赤褐色と白色などが交互に重なる縞模様を持つ天然石です。

その模様は、まるで幾重にも重なった時間や、大切な人との絆を映し出しているかのような美しさを持っています。

赤色からオレンジ色、白色まで、色の濃淡や縞模様の入り方には個体差があります。

古くから装飾品や印章、カメオなどにも利用されてきた歴史があります。

また、流通しているサードオニキスには染色などの処理が施されたものもあるため、天然色や未処理の石を希望する場合は販売情報を確認するとよいでしょう。
