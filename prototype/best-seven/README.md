## 47件の扱い

`review-data.json` と `review/47-tag-review.csv` に47件すべての石ID・分類・原稿引用・根拠ID・理由案・審査区分・未確認事項を収録します。前回の43件は暫定候補で、その内訳は採用推奨25・修正推奨18です。加えて保留3・除外1。前回の採用推奨26のうちモルガナイトの1件は、後続の分類検討で交際状況が不確かなため保留に移されています。

試作の計算対象は**25件のみ**。25件も正式採用ではありません。原稿の該当引用は47件すべて承認原稿と機械照合しましたが、鉱物・流通・歴史的伝承の外部資料本文は未確認です。原稿上の象徴として紹介することと、石の効果や第三者の行動が実際に生じることは異なります。引用範囲の正式な版・根拠グループ、レビュー担当、分類辞書は未承認です。

## 計算ルール・限界

- 99分類のIDを完全一致で扱い、主願いの直接根拠を持つ採用候補だけを選ぶ。「良縁」と「理想の相手」、一般の和解と復縁、愛情と相手から最初のアプローチを同一視しない。
- 主願い・詳細は共通の60点枠で、同じ原稿根拠に対し大分類と詳細の両方を個別加点しない。候補は直接一致のみ、直接一致を60点とする。副願いは任意で最大15点、色10・雰囲気10・用途5点。入力のない任意軸と、全候補を同条件で確認できない軸は全候補で無効化し、共通の分母で100点へ換算する。
- `groupId`は該当引用の仮ID。別引用が同じ主張かどうかを自動推論しない。**重複加点を絶対に起こさないため、この試作では同じ石の全引用を一つの保守的な得点上限 `bundleId` にまとめ、主願いで使用後は副願いに再使用しない。** これは別々の願いもまとめてしまう過小評価であり、正しい意味的な根拠グループが確定したという主張ではない。不明なグループ構造のタグは利用しない。
- 色・雰囲気・形状は外部検証された属性が現在0件のため、一切加点しない。「避けたい特徴」が指定されたときは、該当しないことを確認できない石も除外する。現在は全候補が除外されることがある。未確認を「安全」「一致」とみなさない。
- このため基本ケースは同点になり石ID昇順となる。表示順は石の優劣ではない。結果は最大7件、候補が7件に満たない場合に補充せず不足を明示。0件も正常な「未整備」であり、その願いと合う石が存在しないという意味ではない。
- 同じ入力・データ版・ロジック版の結果は再現可能。データ変更時は版を更新し、過去版とともに保存する設計を正式実装前に決める。スコアは実験的な対応指標で、効果・成功率ではない。
