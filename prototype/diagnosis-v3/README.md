# 診断UX・非公開ローカル試作

このディレクトリは承認前の分類を用いた試作です。Astroの `src/` と `public/` の外にあり、既存の公開診断を変更しません。本番推薦・47タグ・採点・会員・購入・決済はありません。ローカルサーバーは127.0.0.1のみで待ち受けます。URLを共有して公開しないでください。

```sh
npm run prototype:diagnosis
# http://127.0.0.1:4177/
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run prototype:diagnosis:test
```

回答はこのタブのsessionStorageに保存され、サーバーへ送信しません。タブを閉じると消えます。端末間同期はありません。ブラウザの戻る・進むは試作の各操作をたどります。分類・表示文言は確定仕様ではありません。

公開ビルドの監査は、試作ディレクトリ名・試作用データ名・識別子が出力に混ざる場合に失敗します。公開デプロイや検索公開は今回行いません。
